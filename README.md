# coin_converter (archivo, 2024)

Script de aprendizaje. **No es código de producción.** El convertidor de [davito.es](https://davito.es) es de imágenes, no de divisas.

```bash
export EXCHANGE_RATE_API_KEY=...
python converter.py
```

No hay clave en el árbol. Si viste una en un commit antiguo, está revocada de uso: rota la tuya si la reutilizaste.
